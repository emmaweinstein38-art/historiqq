# HISTORIQQ — Rocket-powered history date game

This website is static and can be published for free using GitHub Pages.

## Update your existing GitHub Pages site
1. Open your `historiqq` repository on GitHub (or `historiq` if you haven't renamed it).
2. Open **Add file → Upload files** and upload `index.html`, `style.css`, `script.js`, and `events.js` from this folder. Do **not** upload the ZIP itself.
3. GitHub should show that existing filenames will be replaced. Click **Commit changes**.
4. If GitHub Pages is already configured, refresh your live website after deployment (hard refresh: Cmd+Shift+R on Mac).

The curated events and categories are kept from version 1. Events are limited to 1700–2026. The year range filter only offers events currently in the database.

To change the game's name, wording, visuals, questions or colours, edit the corresponding HTML, CSS, or JavaScript file and upload again.
